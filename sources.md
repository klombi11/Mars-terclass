# Mars Terraclass - Sources

All scientific data and images used in this game come from NASA. Story texts are fictional; the numbers, dates, names and photographs come from the sources below.

## Data and image sources

### 1. Solar flares (Sun mini-game)
- NASA Community Coordinated Modeling Center (CCMC), DONKI API - Solar Flare (FLR) data
  https://ccmc.gsfc.nasa.gov/DONKI-API/get/FLR
- NASA CCMC, DONKI tool page
  https://ccmc.gsfc.nasa.gov/tools/DONKI
- NASA CCMC, Major Updates (DONKI web service location)
  https://ccmc.gsfc.nasa.gov/news/major-updates

### 2. Near-Earth asteroids (Radar mini-game)
- NASA Open APIs - Asteroids NeoWs (Near Earth Object Web Service), data from the NASA/JPL asteroid team
  https://api.nasa.gov/
  https://api.nasa.gov/neo/rest/v1/feed

### 3. Mars surface photograph (Jezero mini-game)
- NASA/JPL-Caltech, Mars 2020 Perseverance Raw Images
  https://mars.nasa.gov/mars2020/multimedia/raw-images/
- NASA Science, Mars 2020 Perseverance mission
  https://science.nasa.gov/mission/mars-2020-perseverance/

### 4. Earth photographs (Earth mini-game)
- NASA/DSCOVR EPIC (Earth Polychromatic Imaging Camera)
  https://epic.gsfc.nasa.gov/
  https://epic.gsfc.nasa.gov/api/natural
  https://epic.gsfc.nasa.gov/archive/natural/
