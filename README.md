# 🚀 Mars-terclass

**Mars-terclass** is a 2D pixel-art, story-driven astronaut training and colony simulation mini-game developed for the **NASA Space Apps Challenge Ankara 2026**.

## 👥 Team Information

- **Contact:** 2009suheybmso@gmail.com

## 🎮 About the Project
Mars-terclass is designed to simulate the essential training procedures and decision-making challenges future Martian explorers will face. Inspired by real NASA data and open-source datasets, the game combines engaging retro pixel-art visuals with educational gameplay mechanics through a series of interactive mini-games.

## 🛠️ Tech Stack & Tools
- **Game Engine:** [Godot Engine 4](https://godotengine.org/) (GDScript)
- **Art & Design:** Custom 2D Pixel-Art Sprites, Tilesets, and HUD UI
- **Version Control:** Git & GitHub / GitHub Desktop
